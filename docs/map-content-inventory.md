# 互动地图内容清单

状态：地图页专属条目已完成坐标校准并接入正式地图
基线：`develop` 分支当前主清单与图鉴数据  
用途：作为下一步地图标点编辑器的条目来源和验收基准

## 已确认的范围规则

- 地图只做地点辅助，不保存“到访/完成”状态。
- 任务类活动、营地请求与同伴活动、悬赏令、挑战地点与路线均不标点。
- 捕兽人服装、强化装备、背包、商店和相关材料均不标点。
- 城镇、车站、商店、营地等通用地区或服务点均不标点。
- 同一实际地点只建一个坐标；多个条目用 `sourceIds` 关联，不重复建点。
- 随机获得、任意地点、纯任务奖励、预购奖励等没有固定世界坐标的内容不建立假标点。
- 本文件只确定范围，不声明任何新坐标；所有坐标均由用户在下一步的编辑器中确认。

## 明确排除

- 所有主线、支线及陌生人任务地点，包括任务获得的武器或奖励位置。
- 所有营地请求与同伴活动。
- 所有悬赏令领取点和目标地点。
- 所有九大挑战地点与骑术路线。
- 所有捕兽人相关服装、强化装备、材料、商店和制作位置。
- 城镇、车站、营地、商店、警局、黑市等通用地点。
- 没有固定来源的随机事件、随机路人、随机掉落和任意地点要求。

## 标点编辑器数据字段

| 字段 | 用途 |
|---|---|
| `markerId` | 地图标记的稳定唯一 ID |
| `sourceIds` | 一个或多个主清单/图鉴条目 ID |
| `category` | 地图筛选分类 |
| `nameZh` / `nameEn` | 中英文名称 |
| `pointType` | `single`、`multi` 或 `shared` |
| `x` / `y` | 相对底图的百分比坐标 |
| `chapterTags` | 章节与尾声限制 |
| `status` | `unplaced`、`draft` 或 `verified` |
| `evidence` | 用户校准备注或来源说明 |

编辑器默认只显示 `unplaced` 条目；保存时导出独立数据文件，不改动清单完成状态。
